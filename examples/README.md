# Examples

This folder contains sanitized examples that are safe to publish.

## `framework-template/`

A sanitized generated `study` workspace. It demonstrates the required native `project/`, the shared `.assay/`, `systems/`, and `knowledge/` base, plus the `sources/` and `analyses/` directories that `study` scaffolds eagerly.

It intentionally does not include real external source material, private notes, runtime logs, generated release artifacts, or secrets.

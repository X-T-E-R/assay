# Agent instructions

A workspace may carry one delimited managed block in `AGENTS.md`, bounded by
`<!-- ABSORB:START -->` and `<!-- ABSORB:END -->`. The block states stable
workspace rules, an object semantics digest, and a directory table composed from
the fixed native resolvers plus custom `layout.entries`. It does not name or
reload the one-shot Template.

`assay init` installs the block unless `--no-agents` is used. `assay update
--agents` installs or refreshes it. Without `--agents`, update only refreshes an
already-present valid block. Incomplete markers are never overwritten
automatically.

`AGENTS.md` is not part of the managed-file receipt, because content outside the
delimiters remains user-owned.

## What the block currently says

In 0.15 the block is generated by the study half's core, so it addresses the
`absorb` binary and carries the five study topics (`workspace`, `project`,
`source`, `analysis`, `knowledge`) rather than the suite's nine. Every rule in
it holds for a suite workspace, and the commands it names are all reachable as
`assay ...` too, but a session driving the workspace through `assay` should read
`assay prime` and `assay explain <topic>` for the merged table. A suite-level
block is not part of this release.

# Releases

Release notes live here before a package or skill distribution is tagged.

Use `NEXT.md` for the unreleased change set. When a release version is chosen,
copy the relevant entries into a versioned note such as `0.1.0.md`, update
package metadata deliberately, run the release checklist, then tag.

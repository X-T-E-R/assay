# Assay 0.6.0

## Trellis Cutover Safety

- Explicit external legacy Channel roots are confined, bounded, strictly
  read-only migration sources. The migration plan records source path, hash,
  filesystem identity, and provenance, then revalidates them before apply
  commits any workspace target.
- `assay trellis hook legacy plan|apply|restore` removes only versioned,
  exact-match legacy Codex writer groups. The operation uses hook-lock CAS,
  preserves neighboring hooks, creates a backup and durable receipt, recovers
  deterministically after interruption, and restores explicitly with
  fail-closed checks.

## Persistence Compatibility

- Fresh manifests use schema 2 with `framework_version: "0.6.0"` and
  `minimum_assay_version: "0.6.0"`.
- Existing schema 1 and schema 2 manifests remain readable. This release does
  not change the workspace layout, plugin protocol, Trellis protocol, or
  Trellis state-schema versions.
